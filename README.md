🌦️ Live Weather Dashboard with Fetch API

A modern, responsive weather dashboard that displays current weather conditions and a five-day forecast for cities around the world. Built using HTML, CSS, and JavaScript with live weather data from the Open-Meteo API.

✨ Features

- 🔍 Search for cities worldwide
- 🌡️ Display current temperature and feels-like temperature
- 🌤️ Weather descriptions and icons
- 💧 Humidity information
- 💨 Wind speed details
- 🌧️ Precipitation information
- 📅 Five-day weather forecast
- ⚡ Asynchronous data fetching using "async/await"
- 📱 Responsive design for mobile, tablet, and desktop
- ❌ Input validation and error messages
- 🔄 Dynamic DOM updates
- 🌐 Free weather API with no API key required

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Async/Await
- DOM Manipulation
- Open-Meteo Weather API
- Open-Meteo Geocoding API

🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in a modern web browser.
4. Enter a city name in the search box.
5. Click Search to view current weather and the five-day forecast.

An active internet connection is required to retrieve weather data.

🌍 API Information

This project uses the following free APIs from Open-Meteo:

- Geocoding API: Converts city names into geographic coordinates.
- Forecast API: Retrieves current weather conditions and daily forecasts.

Website: https://open-meteo.com/

No API key is required for standard non-commercial use under the provider's applicable terms.

🎨 Design Decision

I chose a clean, modern dashboard layout with a soft blue color palette, rounded cards, and weather icons to make information easy to understand. The responsive layout adapts to different screen sizes, while the search interface makes it simple to find weather information for different cities.
